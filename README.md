# Packing List App
A packing list app for creating and checking off trip checklists, and organized by category.

## Features
- **Active Trip checklist** with a progress bar and "Packing Progress" summary
- **Reusable Trip Template** to pick template per trip type
- **Hide / Show packed** to hide or show items that are already packed
- **Category filter** (All and each category) and **search** ("Filter items")
- **Quick add** items with a category and an essential star
- **Essential items** marked with a star, with a counter for remaining essentials
- **Remove** items from the list
- **Edit trip name**
- **Export** the list with check marks, and **Copy** it to the clipboard
- **Save as Template** to reuse the list on future trips
- **Reset** to uncheck all items for a new trip
- **Built-in templates**: Beach / Island, Hiking / Mountain, City Trip, Camping, Road Trip, Business  Trip, Rainy Season Trip, Cold Weather, and Overnight Provincial Trip
- **Use template** to load a list into the Active Trip
- **Create and edit custom templates** (New Custom Template)
- **Works offline**: data is saved on the device with SharedPreferences, so it stays after the app is closed

## Built With
- Flutter (Dart)
- SharedPreferences
- Google Fonts (Plus Jakarta Sans and Inter)

## How to Install and Run
### Android (APK)
1. Download [app-release.apk](https://drive.google.com/file/d/1Ek0w92aBycz6RqJPkFOquqDyBdXVUTVG/view?usp=sharing)
2. Send it to your Android phone and open the file.
3. Tap **Install**. If you see "Blocked," allow installs from that app in the phone's Settings.

### Run on a computer (for developers)
1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Clone the repository:
   ```bash
   git clone https://github.com/VernadithTanacio/Packing-List-App.git
   cd Packing-List-App
   ```
3. Install the dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
